# ScaleCut Agent Instructions

## UI Design Rule

For any UI or UX work in ScaleCut, use the installed design skills before editing:

- `impeccable` for product context, hierarchy, layout, accessibility, polish, and anti-pattern checks.
- `emil-design-eng` for purposeful motion, button feedback, transitions, and microinteractions.
- `high-end-visual-design`, `design-taste-frontend`, or another taste-skill variant for avoiding generic AI dashboard patterns and raising the visual quality.

Treat ScaleCut as a product UI, not a marketing landing page. The interface should serve video editors, creators, agencies, and marketing teams working through real deliverables. Favor clarity, status visibility, calm premium surfaces, keyboard-visible focus, restrained motion, and concrete workflow language.

## Product Direction

ScaleCut is evolving from project scaffolding into an AI-powered creative operations platform. Future UI work should leave room for:

- Creative Cockpit
- Brand Memory
- Prompt Remix
- Style DNA
- Scene Builder
- AI Assets Library
- transcription, subtitles, branding, and multi-platform versioning

Avoid Adobe-like branding, red-first systems, generic AI-purple dashboards, decorative glassmorphism, and oversized landing-page hero patterns.
